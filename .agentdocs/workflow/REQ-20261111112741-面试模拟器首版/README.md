## 目标与范围
实现独立可玩的 React + TypeScript 网页游戏，包含六种背景、职业选择、可复现市场、简历、投递、日程、四类程序员挑战、动态追问、竞争、Offer 谈判、30 天报告及本地存档。其他职业明确标为规划中，不接入外部 AI，不执行任意用户代码。

## 验收标准
1. 能从新建档案进入游戏，自主花费时间、金钱和精力完成求职。
2. 调查、简历、投递、预约、多轮面试、谈判和 Offer 结果具有真实状态转换。
3. 技术问答为文本加追问，算法为受限代码编辑和规则测试，Debug 为代码修复，系统设计为组件装配与约束验证。
4. 同 Seed 的初始市场一致；存档可恢复；第 30 天后有可检查的复盘。
5. 公共基座不导入职业实现；新增职业只需实现并注册协议。
6. 自动化测试及生产构建通过，浏览器验证另行记录。
