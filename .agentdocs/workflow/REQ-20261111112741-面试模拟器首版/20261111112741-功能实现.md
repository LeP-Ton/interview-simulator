## 决策
采用 React + TypeScript + Vite，Vitest 测试纯函数规则。公共状态机接受职业协议，不引用职业实现。以四个每日行动时段模拟机会成本；每日生活费和精力恢复独立结算。两轮面试覆盖四种独立挑战。面试专业表现、客观能力、岗位匹配和录用意愿分别保留。

界面采用暖灰桌面、森林绿强调色、窗口式操作区。所有可操作入口均连接规则引擎，规划职业禁用。

## 实现与影响范围

- `src/core`：纯函数状态转换、集中行动成本、种子市场、资源、简历、投递、预约、面试、Offer、评价、竞争者和 V1 存档。
- `src/core/interviewer.ts`：四类人格的专业、协作、稳定性、抗压、薪资敏感度和追问倾向；印象权重归一化。
- `src/careers/programmer`：技术文本与动态追问、算法编辑、三处故障修复、架构组件与预算装配，独立专业评分和存档草稿校验。
- `src/app`、`src/shared`：完整桌面工作台、启动建档、七个业务页面、弹窗、图标、矢量插画及手机适配。
- 公共职业协议支持独立能力模型、简历内容、岗位专业重点及 1–5 轮面试；通用页面从模块读取流程。
- README、TODO、AGENTS 和 CLAUDE 入口已经建立。仅开发当前空项目，无用户既有业务代码被覆盖。

## 已解决问题

1. 高表现初始报价挤掉谈薪空间：将初始报价控制在预算约九成内，同时保留真实预算与谈判敏感度约束。
2. 不同人格印象权重总和不一致：改为按隐藏偏好归一化，避免人格自带分数膨胀。
3. 结算当帧没有立即读到个人纪录：报告主动同步已完成记录，浏览器验证无需刷新即可显示。
4. 专业侧重仅保存未生效：岗位新增可选 `focusSkill`，专业侧重与实际对应能力进入匹配计算；薪资预期和过度资深同样参与匹配。
5. 手机侧栏只显示图标后缺少可访问名称：为导航和设置补齐中文名称。
6. 跨日后日历仍停留在昨天：日期推进时同步选中当天，已在最终完整流程回归中验证。
7. 移除 Google Fonts 外链，生产游戏无第三方字体或媒体请求。
