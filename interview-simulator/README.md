# 面试模拟器 · 下一站，理想工作

React + TypeScript 网页求职策略游戏，采用模块化单体和可插拔职业模块。首版程序员职业完整可玩；产品经理、设计师、数据分析师明确标记为规划中。

## 运行与验证

环境已验证为 Node.js 20.20.2、npm 10.8.2。建议使用 Node.js 20.20 或更高的兼容版本。

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

开发服务器默认为 `http://127.0.0.1:5173/`；构建输出在 `dist/`，可部署到静态托管服务。不依赖 Google Fonts、外部图片、在线 AI 或后端数据库。

### GitHub Pages 部署

仓库根目录的 `.github/workflows/pages.yml` 在推送到 `main` 或手动触发时，使用 Node.js 22 和公共 npm 安装锁定依赖，依次执行测试、类型检查、生产构建及 Pages 发布。应用仍位于 `interview-simulator/` 子目录。

Vite 的 `base` 为 `./`，脚本、样式与图标均使用相对路径，适配仓库子路径。仓库 Pages 的发布源需选择 GitHub Actions。公开部署使用独立域名，本地存档按浏览器来源隔离；需要延续已有进度时，在旧地址导出 JSON，再到新地址导入。

## 如何游玩

1. 选择程序员、六种背景之一和挑战模式；可输入或随机生成市场种子。
2. 每天有 4 个行动时段。通过市场了解岗位，调查隐藏信息，编辑简历，投递感兴趣的企业。
3. 简历通常在第二天反馈。到日历预约面试，并在预约当天手动进入；每轮预留 2 时段和 22 精力。
4. 首轮为技术问答与算法，第二轮为 Debug 与系统设计。每题独立计时，草稿实时保存；超时自动提交，专业分数上限为 35。
5. 获得 Offer 后，可谈薪三轮、询问福利、协调入职时间；接受或婉拒都可以。只能接受一份 Offer。
6. 第 30 天点击「完成 30 天」，查看完整报告和同种子本地纪录。

学习提升实际职业能力；表达训练提升沟通能力；专业训练和实战提升面试经验。休息恢复精力，隔夜扣生活费并恢复精力。资金不足时进入节俭机制，免费求职行动仍可继续。

## 架构与目录

```text
src/
├── app/                    # 职业注册、桌面外壳和公共页面
│   ├── App.tsx             # 注册、自动存档、操作调度
│   ├── Onboarding.tsx      # 职业、背景、种子和模式选择
│   ├── Workspace.tsx       # 工作台、市场、企业调查
│   ├── Planning.tsx        # 简历、日历、学习
│   └── Results.tsx         # 专业面试容器、Offer、复盘
├── core/                   # 不导入任何具体职业实现
│   ├── types.ts            # CareerModule 和公共结果协议
│   ├── engine.ts           # 纯函数游戏状态转换
│   ├── config.ts           # 背景、平衡参数和行动成本
│   ├── companies.ts        # 虚构企业数据
│   ├── interviewer.ts      # 隐藏偏好和归一化印象评价
│   ├── random.ts           # 可保存状态的种子随机数
│   ├── registry.ts         # 职业注册与协议检查
│   └── save.ts             # 存档版本、导入校验、个人纪录
├── careers/programmer/
│   ├── manifest.ts         # 职业入口、能力、岗位、面试流程
│   ├── content.ts          # 问题、代码样例、组件库
│   ├── ChallengePanel.tsx  # 四种独立专业挑战界面
│   ├── evaluation.ts       # 专业评价及追问有限状态机
│   └── validation.ts       # 专业挑战和草稿的运行时校验
└── shared/                 # UI、图标、矢量插画、响应式样式
```

`transition(previous, action, career)` 创建新状态，不修改旧状态。市场、面试、Offer 和资源都通过该入口转换。核心引擎接收职业协议，不需要知道某个职业如何完成挑战。

## 职业扩展

在 `src/careers/<职业ID>/` 实现 `CareerModule`，然后在 `src/app/App.tsx` 的注册数组中加入模块。其他职业模块和公共生命周期不需要重写。

接口包括：

- `id/name/description/icon`：职业信息。
- `abilityModel/initialSkills`：职业自己的能力维度与初始能力。
- `jobs`：岗位职级、薪资、能力门槛、可选专业重点 `focusSkill`。
- `createResume`：可选的职业简历初始内容。
- `interviewRounds/createInterview`：1–5 轮职业独立流程和挑战描述。
- `practiceChallenges/createPractice`：训练场入口。
- `ChallengePanel`：职业专属 React 挑战组件。
- `evaluateChallenge/review`：统一公共评价与独立专业维度、复盘建议。
- `validateSession`：可选的专业内容和草稿校验。

专业结果存入 `specialized: Record<string, number>`，不要求所有职业共享算法、Debug 等指标。职业状态隔离在 `careers[careerId]`。自动化测试注册了一个仅供测试的独立分析师模块，使用「因果推断」维度、单轮面试，验证从投递到 Offer 的通用生命周期；它没有作为可玩职业展示。

`InterviewAIAdapter` 是未来语义分析、自然语言追问与个性化反馈的接口预留，首版无实现、无网络依赖。

## 规则与公平性

- 初始公司组合、岗位、预算、风险、面试官隐藏属性、竞争者及事件由种子生成；随机状态保存在存档中。相同种子与相同行动序列得到相同市场演进。
- 岗位匹配考虑能力、岗位专业重点、经历、简历证据、薪资预期与职级。过度资深不会自动得到所有岗位满分。
- 面试报告分别展示客观能力、本场专业表现、岗位匹配、面试官印象和企业录用意愿。
- 四类面试官的专业、协作、稳定性、压力、薪资敏感度与追问倾向不同，隐藏数值不可直接查看。调查可了解风格和企业偏好。
- 其他候选人的进度每日推进，岗位可能扩招、调整预算或因经营风险冻结；结果提供原因，不以无解释随机失败惩罚玩家。
- 谈判受预算、表现、其他有效 Offer、面试官薪资敏感度及沟通耐心约束。初始报价预留了合理谈判空间。
- 目标年包包含浮动奖金，基本年薪单独展示；浮动奖金不承诺兑现。
- 自由探索、极速求职、薪资之王、Offer 收割机和理想职业分别计算积分；主动拒绝不合适的机会不会直接判负。

## 首版专业玩法的边界

- 技术问答采用概念关键词、结构、证据和策略规则，状态机区分澄清、核查、深入和补救；不具备完整语义理解能力。
- 算法编辑器支持两数之和的标准 `Map`（哈希表）单遍历、双循环结构。界面列出受限结构检查；不执行任意代码，不等同于真实编程评测。支持的标识符和提示在界面中明确说明。
- Debug 使用购物车问题，分别检查循环边界、数量参与计算、数值返回三项修复结构；不编译任意用户程序。
- 系统设计通过组件装配、实例数量、预算和六项约束评分，并评价失败处理说明。
- 题库规模有限，主要用于完整循环与可扩展机制；更多题型列于 TODO。

## 存档与个人纪录

存档版本为 V1，自动槽与手动槽分离，均使用浏览器 `localStorage`（本地存储）。导入会检查版本、结构、对象引用、职业能力及专业草稿；失败时保留当前状态。支持 JSON 文件导入导出。

面试时限保存为绝对截止时间，关闭或刷新页面不会重置时限。普通求职日期只有点击「结束今天」才推进。

本地成绩按种子、模式与背景比较，只用于个人重复挑战；没有在线排行榜或防篡改承诺。清理浏览器数据会清除存档与个人纪录，建议导出备份。

## 验证证据

- 38 项 Vitest 自动化测试覆盖种子、职业协议及单轮扩展、资源、简历、预约冲突、缺席、两轮四挑战、评分、谈判、过期、结算、存档损坏及隔离。
- TypeScript 严格检查与 Vite 生产构建通过。
- 浏览器实际完成调查、改简历、投递、预约、四挑战、加薪、协商入职、接受 Offer、手动存档、导出导入、刷新恢复和 30 天结算。
- 1440px 桌面和 390px 手机宽度检查，七个主要页面没有横向溢出；未出现浏览器运行异常。
- npm 安装审计结果为 0 个已知漏洞。
